# 工作台基础数据

## `superconductors.csv`

- **用途**：默认模型训练、训练邻近度参考及基础数据分布图。
- **来源**：同一仓库 `LM-based-SC/data/superconductors.csv` 的冻结副本；工作台运行不依赖相邻目录。
- **规模**：12,290 条记录、8,076 个唯一化学式；记录可能包含重复实验或不同实验条件。
- **字段**：`formula` 为化学式，81 个元素列为原子分数，`Tc_K` 为超导临界温度（K）。**`Tc` 是元素锝的特征列，不是温度。**
- **范围**：不含 H/O，且至少含一种金属；排除 Tc > 2 K 的纯 Ga 及逐项核实的薄膜、高压和存疑记录，详见 LM-based 数据说明。
- **SHA-256**：`7ea2fede6f0b3e633f5d388ef35a4bf7ff326898ea670cf58e1271a3b7e076fb`。
- **限制**：约 100 的配比曾按质量百分比假设转换，单位需逐配方核查；部分组成重复，压力、物态和制备条件不作为特征。随机行划分的模型指标不代表严格的组成外推能力。

来源、清洗和引用详情见 [`LM-based-SC/data/README.md`](../../LM-based-SC/data/README.md)；该链接仅用于查阅，工作台不需要相邻项目才能读取本地数据副本。

用户自定义数据及其索引默认统一保存在 `data/uploads/`，与基础数据分开；详见 [`docs/FILE_LOCATIONS.md`](../docs/FILE_LOCATIONS.md)。本工作台不另存非超导数据集。
